# BikeStore – Application iOS

**BikeStore** est une application iOS simple développée avec **SwiftUI**, permettant aux utilisateurs de parcourir une sélection de vélos en ligne.  
Ce projet sert de base pour les applications mobiles de type e-commerce ou catalogue, et illustre les capacités modernes de SwiftUI pour la création d’interfaces.

---

##  Fonctionnalités

- 🛒 Parcourir une liste de vélos soigneusement sélectionnés
- 📸 Afficher les images et détails de chaque vélo
- 💡 Interface simple et élégante grâce à SwiftUI
- ⚡ Navigation rapide et fluide

---

##  Technologies utilisées

- **SwiftUI** – Framework déclaratif pour créer des interfaces sur les plateformes Apple
- **Xcode 15+** – Environnement de développement utilisé
- **iOS 16+** – Plateforme cible
